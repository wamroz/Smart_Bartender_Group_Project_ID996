## About the project
An AI system based on NVIDIA Jetson/Raspberry Pi analyzing the user's facial expression from a photo. Based on the recognized expression, the system automatically controls the pumps and serves an appropriately selected beverage.

## Main modules
1. Vision: Face extraction from the camera.
2. AI: Lightweight convolutional neural network model.
3. Hardware: Controlling relays and pumps via GPIO pins.
